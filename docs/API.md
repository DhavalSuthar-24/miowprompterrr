# API Reference

## Base URL
```
http://localhost:3001
```

---

## Authentication

### POST /auth/register
Register a new user.

**Request Body:**
```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "username": "johndoe",
  "password": "SecurePass123!"
}
```

### POST /auth/login
Authenticate user and receive tokens.

**Request Body:**
```json
{
  "email": "john@example.com",
  "password": "SecurePass123!"
}
```

**Response:**
```json
{
  "success": true,
  "data": {
    "user": { "id": "...", "email": "...", "username": "..." },
    "accessToken": "..."
  }
}
```

## Prompts API

### GET /api/prompts
List prompts with pagination.

**Query Parameters:**
- `page` (default: 1)
- `limit` (default: 20)
- `sort` (hot, new, top)
- `tag` (tag slug)

### POST /api/prompts
Create a new prompt. *Requires authentication.*

### GET /api/prompts/:id
Get prompt details.

---

## Config API

### GET /api/config
Get app configuration (personalities, presets, tiers, templates, options).

## Upload API

### POST /api/upload
Upload an image. *Requires authentication.*

**Request:** `multipart/form-data` with `image` field

**Response:**
```json
{
  "success": true,
  "data": {
    "url": "https://cloudinary.com/...",
    "publicId": "..."
  }
}
```

## Architect API

The Architect Mode allows for stateful, multi-agent orchestration. All endpoints require `Bearer` token authentication.

### POST /api/architect/session
Start a new Architect Session.
- **Body**: `{ "title": "string", "projectDescription": "string", "personality": "string" }`
- **Response**: `{ "success": true, "session": { ... } }`

### POST /api/architect/chat
Send a message to the Orchestrator.
- **Body**: `{ "sessionId": "uuid", "message": "string" }`
- **Response**: `{ "success": true, "message": "string", "data": { ... }, "nextPhase": "string" }`

### POST /api/architect/playground
Simulate a chat with the generated Agent.
- **Body**: `{ "systemPrompt": "string", "messages": [ { "role": "user|assistant", "content": "string" } ] }`
- **Response**: `{ "success": true, "message": "string", "usage": { ... } }`

### GET /api/architect/files/:sessionId
Get the Virtual File System generated by the Executor.
- **Response**: `{ "success": true, "tree": [ ... ] }`

### GET /api/architect/export/:sessionId
Download the entire project as a ZIP archive.
- **Response**: Binary ZIP file.

### POST /api/architect/publish
Toggle public visibility of a session.
- **Body**: `{ "sessionId": "uuid", "isPublic": boolean, "tags": ["string"] }`

### POST /api/architect/fork
Clone a public session into a private workspace.
- **Body**: `{ "sessionId": "uuid" }`
